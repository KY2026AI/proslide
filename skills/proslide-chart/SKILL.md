# ProSlide Chart

图表设计原则：合理、简洁、不误导。

## 一、图表选择规则

根据数据结构和表达目的选择：
- **柱状图/条形图**：类别对比、横向比较
- **折线图**：时间趋势、变化过程
- **饼图**：构成占比（类别少且清晰）
- **堆积图**：总量及组成部分变化
- **散点图**：相关性、分布识别
- **雷达图**：多维指标相对比较

类型不匹配时，建议更合适的图表，不强行绘制。

## 二、合理性约束

- 禁止将量纲不同或数量级差异过大的指标硬塞进同一坐标轴
- 同一图表内颜色不超过 3 种（不含灰阶辅助色）
- 堆积图仅适用于可加总项；目标值建议用虚线框、参考线或独立系列表示
- 坐标轴截断、双轴图、百分比与绝对值混用时必须明确标注口径
- 饼图切片过多时改用条形图

## 三、简洁性约束

- 网格线：默认去掉或极度弱化
- 边框/阴影：图表容器不使用阴影，边框 ≤ 1px
- 数据标签：优先标注关键值，避免全部标注导致遮挡
- 图表过复杂时优先拆图

## 四、默认配色

```js
color: ['#001E50', '#00B0F0', '#C00000']
```

- 主色：核心系列或主结论
- 辅色：对比系列
- 警示色：异常、风险、重点强调
- 灰阶：辅助信息、背景、次要标签
- 不使用 3D 图表和强烈渐变

## 五、页面级要求

- 图表标题应直接表达结论
- 每张图尽量只承载一个核心结论
- 图表服务于页面叙事，不应成为独立展示物
